# Testes realizados

Foram verificados os seguintes casos:

1. Exibir a análise completa de consumo.
2. Perguntar sobre o consumo mensal.
3. Perguntar sobre lâmpada LED.
4. Perguntar sobre energia solar.
5. Fazer uma pergunta fora dos assuntos cadastrados.
6. Digitar uma opção inválida no menu.

A principal melhoria foi deixar as respostas mais curtas e adicionar avisos de que os valores apresentados são estimativas.
